# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.0.0] - Initial Release
### Added
- Dual-Mode Agentic routing (RAG + Text-to-SQL + Hybrid).
- Streaming LLM API with SSE.
- Production-ready LangGraph workflow.
- Enterprise guardrails (Prompt Injection, Jailbreak, Output Validation).
- Prometheus & OpenTelemetry Monitoring.
- Docker Compose Orchestration & CI/CD Pipelines.
- Next.js 15 Frontend with Shadcn/Tailwind design.
